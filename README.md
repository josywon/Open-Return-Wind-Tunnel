# Open-Return-Wind-Tunnel
Open return wind tunnel project logging

Brought to you by Daniel Dorland and Joseph Won

We made an Open Return Wind Tunnel that can accurately test and visualize the aerodynamics of models of cars, planes, jets and rockets.

-Researched and optimized the geometry with Computational Fluid Dynamics analysis using Ansys. Used Python and AutoDesk Fusion to insert a graph as a spline for an optimized contraction cone shape.

-Made a wind speed display using an ESP-32 and Arduino IDE with an LCD screen that reads the variable power supply of the fans. Numbers were calculated using the provided volume displacement of the fan models, and the max velocity calculated in CFD.

-Made a DIY smoke machine with a variable heat/smoke generation for visualizing airflow using a NiChrome circuit and glycerine.
